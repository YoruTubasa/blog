# YoruTubasa 的博客 🦋

基于 **Firefly**(Astro)深度魔改的个人博客。

🔗 在线地址:https://yorutubasa.top

## ✨ 特性

- 黑白极简 UI + 对话式互动首页
- 一言 API 打字机效果(5 秒轮换)
- Waline 评论系统(MySQL 存储,QQ 头像)
- Lsky Pro 图床(img.yorutubasa.top,相册已接入)
- 网易云歌单播放器 + 3D 可视化音乐页
- 动态时间线 / 更新日志 / 日历 / 收藏
- 友链网格 / 标签图谱 / 知识库
- 在线状态自动判定(上下班)
- 性能优化:gzip 压缩、静态资源缓存、安全响应头

## 🚀 开发

```bash
pnpm install
pnpm dev      # 本地开发
pnpm build    # 构建
pnpm preview  # 预览构建产物
```

## 🛠️ 技术栈

- [Astro](https://astro.build) - 静态站点框架
- [Firefly](https://github.com/CuteLeaf/Firefly) - 主题
- [Waline](https://waline.js.org) - 评论系统
- [Lsky Pro](https://www.lsky.pro) - 图床
- [MySQL](https://www.mysql.com) - 数据库
